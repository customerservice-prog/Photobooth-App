# Atelier print artwork

This change replaces the print-design renderer only. It does not change gallery placement, controls, setup behavior, contact collection, printer integration, local photo storage, device pairing or provider flags.

The previous procedural flower icons and ordinary browser type were replaced by an Open Access botanical illustration and outlined display typography. The source botanical work is Henri Joseph Redouté, Rosa Centifolia Anglica Rubra, 1817–1824, Cleveland Museum of Art 1943.137, published under CMA Open Access. The background is removed and the illustration is recomposed into original stationery frames. No paid template, watermarked marketplace preview or commercial design file is copied. Great Vibes, Cormorant Garamond and Montserrat outline adaptations retain their SIL OFL 1.1 notices at /template-licenses. No raw font download is offered to guests.

The static build preparation downloads public artwork/type sources, prepares a transparent botanical asset and derives glyph paths. It is cached within the build. The resulting application bundles the artwork and outlines; the guest iPad does NOT depend on Google Fonts or museum connectivity. New builds fail instead of silently substituting old/basic assets when required art preparation fails.

Wedding: Rosewater Romance (painted rose branches and calligraphic names), The Vow Edit (editorial masthead and large portrait), Black-Tie Heirloom (champagne-colored ornament and formal dark stationery). Birthday: Champagne Birthday, Retro Party Club, Midnight Disco. Other event collections receive the same display typography and appropriate original ornament. All eighteen layouts remain stationary, portrait 4x6 / 1200x1800, and use the same renderer for the screen, export and print. Gold means a printed color effect, not physical metallic foil.

Workflow proof output is generated on a separate design branch before production is changed. The workflow uses the actual built Next app and Playwright Chromium/WebKit, seeded with an illustrative stock photograph and clearly fictional sample event names. It never calls a delivery send endpoint. Generated images and reports are evidence only after their artifacts are inspected; the presence of test code does not mean a test passed. WebKit automation is not physical iPad Safari or Canon certification.
